# DrNowhere mod
This mod not only adds entities, but also changes minecraft a little so that it can be scary. Makes the player lonely in the game - mobs (none at all, even monsters) are no longer compared to him, and there will always be fog in the distance. The player will walk around the world alone and occasionally strange creepy events will occur - the light will turn off, unpleasant sounds will be heard. In the caves, their own unique events will occur. Also, sometimes two monsters will spawn, which may strongly doubt this quiet world without other creatures.
